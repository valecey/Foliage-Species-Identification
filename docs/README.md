## Contributing to Documentation

We welcome contributions to improve the documentation:

### Reporting Issues
If you find errors or unclear sections:
1. Create an issue describing the problem
2. Specify which document needs improvement
3. Suggest corrections if possible

### Submitting Improvements
1. Fork the repository
2. Make your changes to the relevant documentation file
3. Ensure links and formatting are correct
4. Submit a pull request with "docs:" prefix

### Documentation Standards
- Use clear, concise language
- Include code examples where helpful
- Maintain consistent formatting
- Update table of contents when adding sections
- Test all code examples
